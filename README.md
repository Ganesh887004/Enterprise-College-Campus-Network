# Enterprise-College-Campus-Network
College Campus Network designed and simulated in Cisco Packet Tracer using VLANs, Inter-VLAN Routing, OSPF, DHCP, DNS, ACL, NAT/PAT and Layer 2 security features including DHCP Snooping, DAI and Port Security.
## Technologies Used

- VLAN & Inter-VLAN Routing
- OSPF
- DHCP & DNS
- ACL
- NAT & PAT
- DHCP Snooping
- DAI
- Port Security

## Tools

- Cisco Packet Tracer

## Project File

The Cisco Packet Tracer project file (`.pkt`) is included in this repository.
